ことばトラベル／世界マップの印の重なり 修正記録 v1
==================================================

コミットの経緯（先に明記）
--------------------------
この修正のコード（destinations.ts / worldMapScreen.ts / screens.css /
courses.test.ts）は、作業手順の誤りにより、ひとつ前のコミット

に同梱されてしまった。コミットの書き換え（amend）は禁止のため直していない。
コミット名と中身が一致していない点を、ここに記録しておく。
この記録そのものは、次のコミットに入っている。


症状
----
320x568 で、世界マップのロンドンとパリの印が重なっていた。
どちらもロック中で押せないため、学習や進行には影響していなかった。


実測した事実（修正前・Chromium・画素密度2倍）
---------------------------------------------
重なっていたのは「操作領域（印のボタンの箱）」だけで、
印本体（丸）・国名・ロック表示そのものは、どのサイズでも重なっていなかった。

  320x568  枠 296 x 216.5
      ロンドン 箱 64x59 @(81.0, 131.3)
      パリ     箱 46x59 @(107.6, 165.7)
      → 操作領域が 横 37.4px x 縦 24.6px 重なる
  375x667  枠 347 x 367.5   → 操作領域が 横 34.3px x 縦 0.5px 重なる（かすっている）
  393x852  枠 365 x 552.5   → 重なりなし
  402x874  枠 374 x 574.5   → 重なりなし
  430x932  枠 402 x 632.5   → 重なりなし

  どのサイズでも 印・国名・ロック表示どうしの重なりは 0 件、
  枠からのはみ出しも 0 件、横スクロールも無し。


原因
----
印の位置は「枠に対する割合」で置いているのに、印の箱は「固定の px」でできている。

枠の高さは画面によって大きく変わる（320x568 で 216.5px、393x852 で 552.5px）。
低い画面では、割合で置いた縦の間隔だけが一気に詰まる。

  ロンドン y=0.30 / パリ y=0.46 → 差 0.16
      216.5px の枠では 34.6px しか離れない（箱の高さは 59px）
      552.5px の枠では 88.4px 離れる

横の間隔はもともと足りていない。

  ロンドン x=0.34 / パリ x=0.40 → 差 0.06
      296px の枠では 17.8px しか離れない
      重ならないために必要なのは (64 + 46) / 2 = 55px

つまり、広い画面では「縦の間隔」だけが重なりを防いでいて、
低い画面でそれが崩れると、横の間隔では支えきれず重なっていた。


直し方
------
横の間隔を、画面の高さに頼らずに確保する。

・印を描く位置を、地理の位置から横へ px でずらす。
    ロンドン -40px（左へ） / パリ +32px（右へ）
    いちばん狭い枠（296px）でも、中心どうしが 17.8 + 72 = 89.8px 離れる。
    必要な 55px を 34.8px 上回る。
・ずれは割合ではなく px にする。
    割合にすると、大きい画面ほど引出線が長くなり「短い引出線」でなくなる。
    px なので、どの画面でも引出線の長さは 40px / 32px のまま。
・ずらした分、元の位置が分かるように、地理の位置へ小さな輪（10px）を置き、
    そこから印へ短い線を引く。輪と線は押せず、読み上げからも外す
    （aria-hidden）。
・縦はずらしていないので、ロンドンがパリより北、という関係はそのまま。
・印・文字・ロック表示の大きさは一切変えていない。


変えていないもの
----------------
・ロンドンとパリはロックのまま（押せない）。
・日本だけが選べる。選択中のチェック印と強い光もそのまま。
・ボタンの色・光（今回確定した青ガラス）はそのまま。
・学習の進行、出発の操作、読み上げの文言。


ついでに直した小さな不具合
--------------------------
印の aria-pressed が、初回の表示だけ空文字（aria-pressed=""）になっていた。
el() が真偽値の true を "" にするため。読み上げに「選択中」が伝わらない。
世界マップの印だけ String(selected) にして直した。

同じ書き方は courseScreens.ts にも残っている（73行目・118行目）。
今回の指示の範囲外なので手を付けていない。直す場合は連絡をお願いします。

再発を防ぐ検査（src/tests/courses.test.ts）
-------------------------------------------
・いちばん狭い枠（296px）で、ロンドンとパリの印の中心が 55px 以上離れている
・同じく、日本とパリが 45px 以上離れている
・ずらした印には px のずれ量があり、片方向 48px を超えない（引出線が長くなりすぎない）
・ずらしても、ロンドンはパリより西かつ北、日本がいちばん東

ずれ量を外して検査を走らせ、「ロンドンとパリの間隔が 17.8px しかない」で
失敗することを確かめてある。
