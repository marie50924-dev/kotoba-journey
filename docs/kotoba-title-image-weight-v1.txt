3. 候補の作り方
---------------
  Python の Pillow で、元PNGから WebP を書き出した。
    ・構図・色調・配置・切り取りは変えていない。
    ・縮小した候補は、縦横比そのままの縮小（Lanczos）だけ。
    ・透過のある2枚は alpha_quality=100 で、縁を落とさないようにした。
    ・圧縮の手間は method=6（いちばん丁寧）。
    ・元素材は1バイトも書き換えていない。候補はすべて別ファイル。
  背景は必要画素数に足りていないので、縮小する候補は作らない。


4. 画質の測り方
---------------
  候補ごとに寸法が違うので、素材のまま引き算しても比べられない。
  実際に画面へ出る寸法（430x932・画素密度3）へ両方そろえてから比べた。
  透過のある層は、見えない部分の差を数えても意味がないので、
  色の差はアルファで重みをつけ、縁の形はアルファの差で別に見た。
  基準は元のPNG（無劣化）。現行の採用WebPも同じ物差しに並べてある。

6. 採らなかった候補と、その理由
-------------------------------
  人物の縮小（924w）
    容量はほとんど減らない（原寸 q85 239,160B に対し 924w q85 237,220B）のに、
    PSNR は 37.76 → 36.26dB へ下がり、アルファの差が最大19まで出る。
    拡大比較でも、髪の細い筋と透過の縁が甘くなるのが見てとれた。
    **容量が減らないのに画質だけ落ちるので採らない。**

  ロゴの 1000px 幅
    容量は大きく減るが、画素密度3倍で必要な 982px とほぼ同じで余裕がない。
    アルファの差が最大8出て、拡大比較でも文字の縁と星の粒が甘くなる。
    **余裕が無さすぎるので採らない。**

  背景の q75 以下
    石畳の細かい斑が目に見えてつぶれる。**採らない。**


7. おすすめの組み合わせ（1案）
-------------------------------
    背景  background-walkway-candidate-q85.webp  853x1844  427,526B（現行比 76.8%）
    ロゴ  logo-1400w-q85.webp                    1400x552  220,874B（現行比 45.4%）
    人物  characters-q85.webp                    1024x1536 239,160B（現行比 80.4%）
    合計 887,560B。現行 1,340,828B から 453,268B（33.8%）減る。

  画質上の違い
    ・表紙全体を同じ条件で撮って画素で比べると、差の平均 3.65／最大 106。
      差が8以上ある画素は全体の 8.55%で、その大半はロゴの縁と人物の輪郭。
      等倍では見分けがつかない。差が出る場所は差分図で確認できる。
    ・ロゴだけ 1400px 幅へ縮める。画素密度3倍で必要な 982px に対して
      1.43倍の余裕が残る。4倍に拡大した比較でも、現行との差は分からなかった。
    ・人物と背景は寸法を変えないので、顔・髪・透過の縁の形は保たれる
      （アルファの差 0）。
    ・ロゴのアルファの差は最大2。輪郭の形はほぼそのまま。

  控えめ案（ロゴを縮小したくない場合）
    ロゴを logo-fullsize-q85.webp（1997x788 / 395,982B）にすると
    合計 1,062,668B。現行比 79.3%、削減は 20.7%にとどまる。

9. 測定中に直した自分の誤り（2件）
-----------------------------------
  (1) 画像のURLを画面から集めてから待っていたが、集めた時点でまだ1枚も
      貼られていないことがあり、空の配列に対する every が素通りして
      「1.5秒で完全表示」という誤った値が出ていた。
      → 3枚のパスを決め打ちにし、3枚そろうことを条件にした。
  (2) 完全表示の時刻を、確かめ（new Image で読み直す）を終えてから
      記録していた。キャッシュを切っているのでその確かめが3枚を
      もう一度受信してしまい、時間が約2倍（15.8秒）に膨らんでいた。
      → 時刻は待機が終わった直後に記録し、確かめは画面にある img の
        寸法で行うようにした。受信をやり直さない。
  上の8節の値は、どちらも直したあとのもの。
