2. 現在の実装（Version 29・コードを読んで確認）
-----------------------------------------------
一覧の中の人物は、次の2枚のなじませで「人物の側」を透明へ落としている。

  ・横方向（.avatar-thumb__face.has-image に linear-gradient 90deg）
      0〜9% と 91〜100% を透明へ。肩が画像の左右の枠で切れている人の
      まっすぐな切り口を消すため。
  ・楕円（.avatar-thumb__img に radial-gradient 95% x 縦84%・中心 50% 16%）
      下へ行くほど、同じ高さでも左右の端ほど強く落ちる。
      下の左右の角がいちばん先に消える。顔・目・髪は内側なので触らない。
      縦半径は変数（--avatar-fade-y）。画面が低いとき（高さ699px以下・
      幅341px以上）だけ、表示倍率を掛けた人の縦半径を倍率で割る（Version 29 の修正）。
  ・2枚を別々の要素に分けているのは、1つにまとめると mask-composite が必要で、
    対応していない環境で両方とも効かなくなるため。

人物の周りには、何も描いていない。

  ・一覧の中では .avatar-thumb__face.has-image が
      background: transparent / box-shadow: none / border-radius: 0
    になっており、丸い地色・円の切り抜き・円のまわりの影はすべて外してある。
  ・人物の輪郭の外に淡い面や光を出す要素（擬似要素など）は無い
    （avatar.css の中の ::after は、狭い画面で年代タブの押せる範囲を
      広げるためのものだけ）。
  ・人物の背後に見えているのは、カード自身のガラスの面
    （白 24%→14% のグラデーション＋ blur(6px)）と、その向こうの画面の背景。
  ・年代ごとの淡い地色（--age-image-bg）は、共有サムネイル側（旅・出題・
    結果・国紹介の丸いサムネイル）でだけ使っている。一覧では使っていない。


3. 残っている作業
-----------------
受け取ったあとにこちら側で行うこと（実装と測定）
  ・なじませ（人物を薄くする処理）と、くもり（周りへ出す表現）が
    打ち消し合わないことを、画素で測って確かめる。
  ・顔・目・髪に掛からないことを測る（いまの実測値は 1.000＝一切触っていない）。
  ・名前の文字の読みやすさ（4.5:1 以上）を保つことを測る。
  ・カードの切り取り線（縁の内側）で、くもりが横一文字に切れないことを、
    切り取りあり／なしの撮り比べで測る。
  ・80人ぜんぶで同じように見えることを測る。

この段階では試作までとし、確認版 Version 29 の更新と、正式サイト・main への
反映は保留する。Version 29 の実機確認は「ぼかし作業前の現状について問題なし」
という記録のまま維持する。

6. いま進められないこと（見本が手元に無い）
-------------------------------------------
IMG_5361(1).jpeg と IMG_5360(2).jpeg は、この作業環境に届いていない
（添付の置き場所は空で、環境内を探しても同名のファイルは無い）。
見本を見ずに範囲・濃さを決めると、デザインを独断で決めることになるため、
試作はここで止めている。見本を受け取りしだい、第4節の条件で試作して
同じ条件の比較を出す。

なお、過去の見本は assets-source/ の中に置き場所を作って保管している
（例：assets-source/title/button-reference-20260929/IMG_5245(1).jpeg）。
今回の2枚も、受け取ったら同じやり方で保管する。
