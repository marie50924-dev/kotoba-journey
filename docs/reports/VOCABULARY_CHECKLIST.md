# ことばトラベル 語彙確認チェックリスト（基本30語）

このファイルは、カルタの札に使うことば **30語** を、人が資料で確かめるための台帳です。

- 作成時点: 工程 V-2C-1
- 対象: 現在ゲームで使用中の10語 ＋ まだコードに入れていない新規候補20語
- **作成時点では、30語すべてが未確認です。**「確認済み」は1語もありません。

---

## 1. このチェックリストは何か

ことばトラベルは、日本語と英語のことばを合わせて覚えるカルタのゲームです。
札に出す一語一語が、日本語と英語で本当に対応しているかを、人が資料で確かめた記録をここに残します。

これは**制作上の品質管理の記録**です。ゲームの動作を止めたり、画面の表示を切り替えたりする仕組みではありません。

### 国紹介の出典チェックリストとは別物です

ことばトラベルには、もう1つ別のチェックリストがあります。
`docs/reports/COUNTRY_GUIDE_JAPAN_SOURCE_CHECKLIST.md`（国紹介の出典チェックリスト）です。
両者は目的も仕組みも別で、次のとおり**完全に切り離されています**。

| | 語彙チェックリスト（このファイル） | 国紹介の出典チェックリスト |
|---|---|---|
| 対象 | カルタの札のことば | 国の紹介文（事実の記述） |
| データ上の扱い | `FactClaim` ではない | `FactClaim` / `InfoSource` |
| 状態の呼び方 | 要確認（使用中）／要確認（候補）／確認済み | `body-checked` / `rejected` / `withdrawn` など |
| 確認日の記録先 | このファイルの「確認日」欄 | `InfoSource.checkedAt` / `FactClaim.checkedAt` |
| 画面への影響 | なし | `publicationStatus` と `canPublish()` で公開を止める |

次のことを、はっきりさせておきます。

- 語彙は国紹介の `FactClaim` **ではありません**。
- 語彙の確認状態は、国紹介の `canPublish()` に**影響しません**。
- 語彙の確認状態は、日本の `publicationStatus` に**影響しません**。
- 語彙の確認が全部終わっても、国紹介は**自動で公開されません**。
- 語彙の確認状態に `body-checked` / `rejected` / `withdrawn` という名前は**使いません**。
- 語彙の確認日と、国紹介の `checkedAt` は**別の記録**です。

## 2. 状態の3種類

| 状態 | 意味 |
|---|---|
| `要確認（使用中）` | いまゲームで使っているが、この台帳ではまだ人の確認記録がない |
| `要確認（候補）` | まだゲームに入れていない。人が確認したあとで採用を決める |
| `確認済み` | 人が資料を確かめ、単独の札として採用してよいと判断した |

見送ることになった語は、状態を増やさず、**判定欄に `見送り` と書く**運用にします。

作成時点の内訳は次のとおりです。

| 状態 | 件数 |
|---|---:|
| `要確認（使用中）` | 10件（pairId 1〜10） |
| `要確認（候補）` | 20件（仮pairId 11〜30） |
| `確認済み` | **0件** |

---

## 3. 人が「確認済み」にできる条件

次の10項目が**すべて**そろったときだけ、状態を `確認済み` にできます。

1. 記録するURLそのものを、人が実際に開いた
2. 日本語と英語の対応を、本文・見出し・語彙項目のどれかで確認した
3. 辞書の定義文をそのまま写さず、確認した内容を短く要約した
4. 単独の札として出したときに、誤解が大きくないことを確認した
5. 品詞を確認した
6. ゲーム内の規則（**名詞は単数形・動詞は原形**）に合っている
7. 多義語のときは、札だけで対象の意味に限定できることを確認した
8. 表記を直す必要があれば、直したあとの日本語・英語を記録した
9. 採用／修正／見送りのどれかを記録した
10. 確認日を記録した

**してはいけないこと**

- 資料の候補を見つけただけで `確認済み` にする
- 検索結果の要約だけを根拠に `確認済み` にする
- ページ本文を開けなかったのに、推測で内容を補う

本文を確認できなかった語は `要確認` のままにし、何が確認できなかったかを「確認した内容」欄に書いてください。

## 4. 資料の扱い

**作成時点では、資料欄・URL欄はすべて空欄です。** 推測でURLを入れていません。

これから確認するときの、資料の優先順位です。

1. 公的な教育機関・国立大学などの学習資料
2. 出版主体がはっきりしている、学習者向けの英英辞書・英和辞書
3. 出版主体がはっきりしている国語辞典
4. そのほか、編集の責任者がはっきりしている資料

避けるもの

- 出典のわからないまとめサイト
- 個人のブログ
- 自動翻訳の結果だけ
- 検索結果の抜粋だけ
- 市販教材の語彙一覧の転載
- 英検・TOEIC対策の語彙リストのコピー
- AIの回答だけを根拠にすること

辞書の定義文は、このファイルへ写さないでください。
「名詞として apple が『りんご』に対応することを確認」のように、**短く要約して**書きます。

## 5. 仮pairId と 正式pairId の違い

| | 仮pairId（11〜30） | 正式pairId（1〜10） |
|---|---|---|
| どこにあるか | このチェックリストの中だけ | `src/data/wordPairs.ts` |
| ゲームに出るか | 出ない | 出る |
| 保存データから参照されるか | されない | される |
| 変えてよいか | 実装するときに振り直す | 変えない |

仮pairId は、人が確認するときに語を指し示すための番号です。

**見送りが出ても、欠番は作りません。** 実装の工程で、採用した語だけに連番を振り直します。
たとえば仮22が見送りになっても「22番が空き」にはせず、採用語を 11, 12, 13… と詰めて確定します。

---

## 6. 既存10語の扱い

pairId 1〜10 は、いまゲームで使っていることばです。
この台帳ではまだ人の確認記録がないため、すべて `要確認（使用中）` にしてあります。

**未確認であることを理由に、次のことはしません。**

- 既存10語をゲームから外す
- 表記を変える
- `pairId` を変える
- ゲームを止める
- 国紹介のような公開ゲートを、ことばの側にも作る

このチェックリストは制作上の記録であって、動作中の公開判定ではありません。

---

## 7. 新規候補20語の扱い

仮pairId 11〜30 は、**まだコードのどこにも入っていません**。

- `src/data/wordPairs.ts` へ追加していない
- ゲーム画面へ出していない
- 語彙セットへ入れていない
- 正式な `pairId` として確定していない
- 保存データから参照していない

人の確認結果を受け取るまで、候補語をゲームへ追加しません。
