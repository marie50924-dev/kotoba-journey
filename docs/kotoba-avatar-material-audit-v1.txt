2. ID・氏名・元素材ファイルの対応（manifest と突き合わせ）

各 manifest の SHA-256 と、リポジトリの assets-source/avatars/<ID>.png を照合した。

  小学生・女子 8／小学生・男子 8／中学生・女子 8／中学生・男子 8

  大人・女性 8／大人・男性 8

並び順からの推測はしていない。対応は manifest の id と sha256 で決めている。
決定画像（IMG_5076/5079/5080/5081/5089 など）の「何枚目が誰か」は、
今回それらの画像が届いていないため照合していない（第6節）。


3. 腰から上の元画像があるか
---------------------------
個別の「腰から上」の元イラストは、確認できた範囲では存在しない。

  ある：1254x1254 の個別PNG 80枚。胸から上（肩と襟の上部まで）で、
        画像の下辺で胴が切れている。背景は透明。丸い形は画像に入っていない。
  ある：丸く見えるのはCSSの指定（border-radius: 50% と地色）だけ。
        一覧ではすでに外してあり、画像を丸く切った素材は無い。
  ない：腰から上が1枚で描かれた個別ファイル。

カードで腰から上に見せていたのは、顔の原画と「生成した補完胴体」の組み合わせ。
  素材セット v13〜v23（screen-reference）
    middle-f-01.png / middle-m-01.png … 原画（リポジトリの元PNGとバイト一致）
    body-f.png（1102x1427）/ body-m.png … ChatGPTが生成した補完胴体。男女で共用
    body-mask / body-blend / head-blend（800x1040・800x800）… 合成用
    center-*-mask / rim-*-mask / frost-*-mask / footprint-*-mask（800x1040）
      frost が、カード内側の白いくもりにあたるマスク
  個人別カード一式（11名ぶん）
    head.webp（その人の配信WebPの無改変コピー）／body-generated.png（生成胴体）
    body-mask／center-mask／rim-mask／frost-mask／head-blend／background.png
    attach-<名前>.ts／<名前>-integration.css／build_masks.py／preview／SHA256.txt
