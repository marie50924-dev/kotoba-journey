## 実装ルール

- IDは保存データの主キーとし、名前を主キーにしない。
- 会話本文は `{speakerAvatarId}` から名前を解決する。
- 名前を後から調整しても学習記録や親密度を失わない。
- 日本語UIでは `givenName`、プロフィールでは `familyName + givenName`。
- 英語UIでは `romanizedName` を使用する。
- プレイヤー本人の実名入力は要求しない。
