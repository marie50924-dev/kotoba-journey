2. 作品・役割・維持する基本条件
-------------------------------
作品：ことばトラベル（KOTOBA JOURNEY）。
      子どもから大人まで英語を学ぶスマートフォン向け Web アプリ。
ChatGPT：イラスト、素材、見た目、制作指定と採否の判断。
Claude Code：受領した素材・指定を実装し、機能へ接続、撮影・測定。
      独断で人物やマスクを制作・調整しない。
技術：HTML / CSS / TypeScript、Vite、Vitest、Playwright。
      サーバー送信・ログイン・課金・広告SDK なし。
対応サイズ：320×568 / 375×667 / 393×852 / 402×874 / 430×932。
人物：80人、各年代16人（男女8人ずつ）。人物ID・氏名・採用原画の対応を維持する。
他作品（ブラストブロック等）の素材・リポジトリを混ぜない。
