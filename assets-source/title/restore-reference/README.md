# 表紙復元・添付の6枚目と7枚目を基準にする

## 出典と優先順位

1. `background-reference-exact.jpeg` はユーザー添付6枚目 IMG_5217(1).jpeg のバイト一致コピー。背景の名所、地球儀の大きさと位置、光の流れはこれを基準にする。ロゴ・人物・ボタンは含まない。709×1536 RGB。
2. `target-composition-old-faces.jpeg` はユーザー添付7枚目 IMG_5214(1).jpeg のバイト一致コピー。ロゴの見え方、人物の大きさと配置、人物の間から足元へ広がる光、青い開始ボタン、副ボタンの青紫の透明感を基準にする。顔だけは古いので採用しない。709×1536 RGB。
3. `characters-new-faces.png` は以前制作した分離人物の透過素材。顔・肌についてはこちらの優しい男性顔と明るい肌を優先する。1024×1536 RGBA。人物配置は7枚目を目標に調整する。
4. `logo-transparent.png` は既存の透過ロゴ素材。1997×788 RGBA。7枚目の見え方を目標に大きさ・位置・発光と透け感を調整する。

## 実装に関する指示

前回作成の background-v2（巨大で上に寄った地球儀）は使わない。`background-reference-exact.jpeg` を最初の候補として実際に表示し、7枚目と並べる。既存の分離素材方式・本物のDOMボタンを維持する。ボタン絵を背景に焼き込まない。

以前設けた「地球儀の円周とロゴ・人物の重なり0px²」は、この7枚目の構図と矛盾するため、この復元作業では絶対条件としない。7枚目では大きな地球儀が背景として人物とロゴの後ろにあり、主要な青い球面が見えている。何を見せたいかを画像の目視で確認すること。富士山の山頂と名所、人物の顔と全身、操作は欠けさせない。

強い光は地球儀の縁ではなく人物の間の奥から足元に広がる。7枚目のCTAは鮮やかな透ける青いピル型で白水色の柔らかい発光。副ボタンは濃い青紫のガラス感、細い白縁、背景の透けを残す。数字で重なりを0にするためにロゴを縮めたり、人物を小さくしたり、中央の光を消したりしない。

7枚目は顔が古いので、絵全体をそのまま表紙に敷かない。実装後、320×568・375×667・393×852・393×745・393×700・430×932で画面全体の無加工見本を提示し、7枚目と同じ表示幅で視覚比較する。iPhone 15 Pro Safari実機は未確認として扱う。mainへは反映・公開しない。
