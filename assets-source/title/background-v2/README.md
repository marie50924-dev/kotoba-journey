# ことばトラベル表紙・背景候補 v2

`background-large-globe-center-light.png` は 852×1846 RGB の背景のみの画像。ロゴ、人物、かばん、ボタンは含まない。旧 `background.png` より大きな地球儀を中央上方に置き、強い暖色の光の中心を地球儀の下の街路中央（重ねる二人の間）に置いた。`original-light-reference.jpeg` は今回ユーザーが示した当初の構図。正式採用の青いロゴ・明るい肌・優しい男性顔・実DOMボタンは既存の分離素材とコードで重ねる。

この新背景は候補であり、組み合わせたアプリ画面は未検証。地球儀が大きくなったため、既存の地球儀矩形やロゴ・人物の位置制約（21〜33%など）はもはや正しくない。変更前に新しい実際の絵柄範囲を再測定し、すべての対応画面でロゴ、地球儀、人物、富士山、操作の配置を見本で確認すること。球の円周を隠さないために人物が過度に小さくなるなど両立しない場合、勝手にどちらかを犠牲にせず具体的な画面見本と制約を報告すること。ボタンの透明感とロゴの大きさも前回の修正指示に従う。`main`には反映しない。
