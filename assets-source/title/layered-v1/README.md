# ことばトラベル 表紙・分離素材 v1

最終承認見本は `approved-preview.png`。実装用素材は `background.png`、`logo.png`、`characters.png` の3点です。

| ファイル | 画素数 | 形式 | 用途 |
|---|---:|---|---|
| approved-preview.png | 852×1846 | RGB | ユーザーが正式採用した完成見本。実装に直接敷かない |
| background.png | 852×1846 | RGB | ロゴ・人物・かばん・ボタンを含まない全面背景 |
| logo.png | 1997×788 | RGBA | 透過ロゴ。文字は「ことばトラベル」「KOTOBA JOURNEY」 |
| characters.png | 1024×1536 | RGBA | パイロット、CA、手荷物、かばんの透過グループ |

これらは完成見本を参照して個別に制作したため、重ねるだけで元の画像と画素単位で一致するわけではありません。特に人物の大きさと顔、富士山・地球儀の見え方、ロゴとの距離は実画面で照合してください。素材そのものを勝手に描き直すのではなく、まずCSS配置を調整し、解決できない場合は具体的な差分を報告してください。

`characters.png` と `logo.png` は実アルファ付きです。ブラウザでは透明部分をそのまま扱ってください。背景だけ cover とし、ロゴ・人物には contain を用い、人物の靴・かばんが主ボタンより上にあるよう配置してください。地球儀の円周はロゴ・髪・人物で隠さないでください。富士山の山頂と山体を見せてください。画面下部に「旅をはじめる」「マイパスポート」「設定」を文字を持つ実DOMボタンとして配置し、画像のボタンを重ねて二重表示しないでください。

表示検証：320×568、375×667、393×852、393×745、393×700、430×932。Safariのアドレスバーと安全領域を考慮する。左右余白、ロゴ・人物の欠け、地球儀・富士山の遮蔽、ボタン重なり、44px以上の操作領域、キーボード操作、横スクロールを確認する。Chromium模擬とiPhone 15 Pro Safari実機の確認は区別する。

このZIPの制作時点ではアプリのリポジトリに変更しておらず、3素材をアプリで重ねた画面の実ブラウザ確認も未実施です。mainへの反映・公開はユーザーの実機確認前に行わないでください。表紙の確認ができたら、保留中の主人公選択の再設計を再開してください。学習後の確認テストは直接入力のまま維持してください。
