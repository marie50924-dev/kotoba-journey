# 表紙の接地とロゴ：制作側の修正候補

- `background-walkway-candidate.png`：背景のみ。石畳の歩道が遠景から手前まで途切れず続き、現行の人物の靴がある高さにも石畳がある構図。画像生成のため、基準6枚目の上部まで画素一致ではない。ユーザーの採用はまだない。
- `logo-glow-candidate.png`：透明ロゴ候補。7枚目の白銀文字と淡い青い発光・ぼけた外周に近づけた。表記を画面見本で必ず確認する。ユーザーの採用はまだない。
- `target-cover-reference.jpeg`：ユーザーの7枚目の完成イメージ。顔のみ旧仕様なので人物顔の基準にはしない。
- `floating-current-reference.jpeg`：現行画面。靴が石畳の始まりより上にあり、足元の背景が川・欄干で浮いて見える状態。

まず作業ブランチの外で背景とロゴの候補を既存の透過人物・実DOMボタンに重ね、393×852で同じ表示幅の比較を作る。接地判定は人物の矩形下端とボタンの距離ではなく、男性の左右の靴底、CAの左右の靴底、かばんの脚の各位置に石畳があるか、遠近法が合うか、局所的な接地影があるかを目視・座標で確認する。影は必要ならCSSの小さな楕円影を足元に置くが、地面が川のままなら影だけで解決したことにしない。

ロゴは7枚目を基準に字形・白銀の面・青い透ける雲状の光・上部配置を比較する。新候補へ差し替えれば必ず一致すると仮定しない。人物の採用済み新しい顔、富士山と名所、光の中心、3つのボタンのガラス感を守る。iPhone 15 Pro Safari実機は未確認として扱う。ユーザーの見本確認まではmainへ反映しない。
