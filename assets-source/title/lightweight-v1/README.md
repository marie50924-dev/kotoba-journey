# 表紙3枚の軽量化 候補（試作・未採用）

ここにあるのは **試作の候補** で、アプリはまだ1枚も参照していない。
採用が決まるまで `public/assets/title/` 以下は変えない。

元素材（`assets-source/title/grounding-v1/*.png`、`assets-source/title/layered-v1/*.png`）は
そのまま残してある。候補はすべて、その元PNGから作り直したもの。

## 作り方

Python の Pillow で WebP として書き出した。

- 構図・色調・配置・切り取りは変えていない。
- 縮小した候補は、縦横比そのままの縮小（Lanczos）だけ。切り取りはしていない。
- 透過のある2枚は `alpha_quality=100` で、縁を落とさないようにした。
- 圧縮の手間は `method=6`（いちばん丁寧）。

## 置いてある候補

| ファイル | 寸法 | 容量 | 設定 | 位置づけ |
|---|---|---|---|---|
| background-walkway-candidate-q85.webp | 853x1844 | 427,526B | 原寸 / quality 85 | **おすすめ** |
| logo-1400w-q85.webp | 1400x552 | 220,874B | 1400px幅へ縮小 / quality 85 | **おすすめ** |
| characters-q85.webp | 1024x1536 | 239,160B | 原寸 / quality 85 | **おすすめ** |
| logo-fullsize-q85.webp | 1997x788 | 395,982B | 原寸 / quality 85 | 縮小を避けたい場合の控えめ案 |

おすすめの3枚で 887,560B。現行の 1,340,828B から 453,268B（33.8%）減る。

## 縮小してよいかの判断

対応する画面のいちばん大きいサイズ（430x932）で、画素密度3倍のときに必要な画素数は

- 背景 1293x2796 … 素材 853x1844 は**すでに足りていない**ので縮小しない
- ロゴ  982x388  … 素材 1997x788 は約2.03倍。1400px幅でも1.43倍の余裕が残る
- 人物  925x1387 … 素材 1024x1536 は約1.11倍。縮小しても容量はほとんど減らず、
                   髪の細い筋と透過の縁が目に見えて甘くなったので縮小しない

詳しい比較は `docs/kotoba-title-image-weight-v1.txt` を見ること。
